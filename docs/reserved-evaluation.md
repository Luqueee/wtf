The strict 1/7 gain with 1/7 false statement plus development adversarial regressions does not justify default promotion. A small, hand-built corpus cannot estimate a population improvement or a statistical confidence interval.

Costs: no-model replay ~15.5–16.3 ms/case; Phi cold per-invocation model replay **1.516–1.816 s** visible (median **1.616 s**). Every replay starts/stops its own model process; persistent-server warm median ~0.444 s was measured on development prompts only. Device baseline occupied 13 MiB by other processes; independent forced 192-token measurement on this RTX 4060 Ti observed **2,853 MiB total peak** (load 2,847, request 2,853; product context 2,048 and prompt 192 tokens). See [`model-candidates.md`](model-candidates.md) and the raw GPU samples in `scripts/lab/artifacts/dev/phi-memory.json`. Polling can miss sub-50 ms spikes, and this sample says nothing about other devices or concurrent GPU loads. Laya was not run: its closed-set hypothesis-ranking interface cannot interpret unseen stdout/stderr and would not be an informative generic-output comparator.

The separate **real CLI** smoke after the frozen reserved run executed `/usr/bin/tar -tf /dev/null` once: exit 2, observed `This does not look like a tar archive`, Phi added a POSSIBLE paraphrase and a file-type NEXT. A real `python3 -m wtf_nonexistent_module` (unknown executable) also ran once and retained exit 1; the model invented an invalid timestamp evidence ID, so the deterministic report remained. These exercises prove CLI reachability and fallback, **not** a new diagnostic improvement. No opt-in shell capture beyond explicit `wtf -- PROGRAM` was added; the shell hook still has no stderr.

**Generalización fuera del corpus: no establecida.** The interpreter stays opt-in. Further work would require a more varied independent corpus and semantic factual safeguards, especially where a plausible stderr line may be deliberately misleading. These observations cannot establish a model's historical-cause accuracy or guarantee arbitrary-secret redaction.
